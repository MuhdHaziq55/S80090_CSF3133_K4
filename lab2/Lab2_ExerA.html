About the Event

The Programming Workshop 2026 is a one-day event organised by the Faculty of Computer Science. Students will learn programming skills, explore new technologies and participate in practical coding activities.

Speaker 1: Mr. Ahmad Rahman

Mr. Ahmad Rahman is a software developer who will share his knowledge of programming fundamentals and introduce students to modern software development techniques.

Speaker 2: Ms. Siti Aminah

Ms. Siti Aminah is a web developer who will guide students through a hands-on HTML workshop and explain how to create a basic web page.
